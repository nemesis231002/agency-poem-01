A short poem about agency — the power to choose and to act, and the agency
that passes between a person and an AI agent when one acts for the other.
Written for make.fun's "Write the best poem about agency" bounty, $250 in USDC.

The poem is about delegation that lets an unbearable task proceed, and the
speaker's power to take it back with a single word: *Wait*.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the poem to
`/output/entry.txt` — or to `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the
grader's container. It is fully deterministic: no network, no randomness,
no time or environment input, so two runs write the same bytes.
